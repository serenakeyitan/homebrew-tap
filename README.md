# TokenTorrent Homebrew tap

Install the TokenTorrent CLI on macOS:

```sh
brew install serenakeyitan/tap/tokentorrent
```

Then sign in at [tokentorrent.pages.dev](https://tokentorrent.pages.dev), open
your Buyer or Seller dashboard, and use **Connect this Mac**.

Alternative package-manager installs:

```sh
npm install -g tokentorrent
pnpm add -g tokentorrent
```
